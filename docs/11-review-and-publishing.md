# Review and publishing

Only public apps and external integrations go through moderation. Moderation keeps the directory safe for users.

## Before you submit

- [ ] App tested end to end: install → app opens → API call works → uninstall returns `200`.
- [ ] Install URL and Uninstall URL are public HTTPS endpoints.
- [ ] Only the scopes the app actually uses are selected.
- [ ] English description, key features and setup guide are filled in and match what the app does.
- [ ] Logo 250×250 px; screenshots up to 1600×900 px taken with English UI.
- [ ] Support email is monitored (review results arrive there).
- [ ] Privacy Policy link works.
- [ ] Translations added for target markets (optional).

## Submit

- App: **App directory → Home → Created → Applications → ⋯ → Submit for review**.
- External integration: same path, **Integrations** tab.

Review takes up to **2 business days**. The team contacts you at the support email.

A private app submitted for review becomes public after approval.

## Track status

See the **Status** column in **Created**.
